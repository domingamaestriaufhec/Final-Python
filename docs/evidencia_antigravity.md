# 🤖 Evidencia de Desarrollo Agéntico: Google Antigravity IDE
## Proyecto: InvestigaLab (Plataforma y Curso de Metodología de la Investigación Científica)

---

## 📌 1. Entorno de Desarrollo Agéntico
Este proyecto fue construido utilizando **Google Antigravity IDE**, una plataforma agéntica avanzada orientada a la ingeniería de software asistida por modelos de lenguaje y ejecución de herramientas contextuales.

---

## 🛠️ 2. Componentes y Metodologías Implementadas

### A. Planificación Agéntica (*Plan-First Approach*)
* Desacoplamiento riguroso de la arquitectura en capas: **Capa Técnica** (Flask, Jinja2, CSS, Enrutamiento) y **Capa de Dominio/Idea** (`levels_data.py`, `books_data.py`).
* Diseño modular con factoría de aplicaciones (`create_app`) y blueprints para garantizar escalabilidad.

### B. Customizations & Skills Personalizadas (`.agents/skills/`)
* Se desarrolló la skill `flask-docs-architect` ubicada en `.agents/skills/flask-docs-architect/SKILL.md` para estandarizar la arquitectura y documentación de proyectos web en Python.

### C. Protocolo MCP (*Model Context Protocol*)
* Integración de servidores MCP en `.mcp.json` para la coordinación de herramientas y soporte de desarrollo.

### D. Automatización de Entornos y Despliegue
* Gestión automatizada del entorno virtual `.venv` y resolución de dependencias.
* Configuración de despliegue continuo en **Render** mediante `Procfile` y repositorio remoto en **GitHub**.
